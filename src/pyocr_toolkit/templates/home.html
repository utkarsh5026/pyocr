How it works

  1. UploadAny PDF or image. Pages without a real text layer are flagged as scans.
  2. ExtractRun Tesseract or an LLM on one page, a page range or the whole document. Results are cached.
  3. Inspect & comparePage image next to each text, word-level diffs, character/word error rates, search with highlights.
  4. ExportWhole-document text as TXT, Markdown, JSON or JSONL (one page per line for RAG / ingestion).
