Models your key can use

Asks the provider's API which models your credentials can use, then rates each one. Azure deployments can't be listed this way: type the deployment name on the Providers page instead.

How the ratings work

  • Excellent for OCR near the top of public OCR benchmarks, or the vendor's top vision tier. Use for handwriting, tables, poor scans.
  • Good for OCR reliable on most printed documents; good value for bulk jobs.
  • Fair: clean print only cheap or old models; expect skipped or "fixed" text on hard pages.
  • Not suitable can't read images (embeddings, audio, image generators, text-only).
  • Not rated a name that isn't in the catalog (custom, fine-tuned, local). It may work fine: run Test connection, then Compare it against another source.

“benchmark” means the rating rests on a published OCR result; “vendor” means it's estimated from the vendor's docs and model tier. Benchmarks disagree and go stale, so measure on your own pages with the Compare tab.
